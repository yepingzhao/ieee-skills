# IEEE Conclusion Section Polishing

## Job: Summary of contributions, not a repeat of the abstract

## Structure
1. Restate the problem and approach (1 sentence)
2. Summarize key contributions (numbered or bulleted)
3. State the main quantitative finding (1 sentence)
4. Suggest future work (1-2 sentences, be specific)
5. Closing statement of impact (1 sentence)
