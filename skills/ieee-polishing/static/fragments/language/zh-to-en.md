# Chinese → English Translation Rules (IEEE)

## Philosophy
Translate intent and argument, not clause order. Chinese academic prose often places the main point at the end of a paragraph; IEEE English places it at the beginning.

## Process
1. Read the full Chinese paragraph for meaning
2. Identify the core claim
3. Write an English topic sentence stating the claim
4. Build supporting evidence sentences
5. Add citation markers where needed

## Common transformations
- Chinese: "通过...方法，我们..." → English: "We [verb] using [method]..."
- Chinese: long noun phrases → English: break into clauses
- Chinese: implicit connections → English: explicit transitions
- Chinese: no articles → English: add a/an/the
