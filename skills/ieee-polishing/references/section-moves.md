# IEEE Section-Level Rhetorical Moves

## Introduction moves
1. Establish territory (broad field significance)
2. Establish niche (specific gap or problem)
3. Occupy niche (present work as solution)

## Results moves
1. Present finding (quantitative)
2. Explain method that produced it (brief)
3. Compare to baseline
4. Interpret (reserve deep interpretation for Discussion)

## Discussion moves
1. Restate main finding
2. Compare to prior work
3. Explain mechanism or reason
4. Acknowledge limitation
5. State implication
