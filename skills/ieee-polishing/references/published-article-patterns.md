# Curated IEEE Article Patterns

## Observed patterns from published IEEE Transactions papers

### Abstract pattern
"X is a critical challenge in [field]. Existing methods [limitation]. This paper presents Y, which [key insight]. Experiments on [datasets] show [key numbers]. Y achieves [improvement] over [baseline]."

### Introduction pattern
"[Field] has seen rapid progress in [narrow area]. However, [specific bottleneck] remains unsolved. Prior work has attempted [approach 1], [approach 2], but these [limitations]. To address this gap, we propose [method]. The key contributions are: 1) [contribution 1]; 2) [contribution 2]..."

### Results paragraph pattern
"Fig. N shows [key observation]. [Method] achieves [X]% on [metric], compared to [Y]% for [baseline]. This improvement is most pronounced for [condition], where [explanation]. Table [n] reports full results across all [n] benchmarks."
