# IEEE Style Guardrails Checklist

## Pre-submission audit
- [ ] All citations are numbered [1], [2], [3] in order of first appearance
- [ ] All acronyms defined at first use
- [ ] All numbers with units: "10 ms" (space before unit)
- [ ] All figures/tables referenced in text before they appear
- [ ] No "very", "extremely", "obviously", "clearly"
- [ ] No "It is worth noting that..."
- [ ] No "To the best of our knowledge" (be specific)
- [ ] et al. in italics: *et al.*
- [ ] "data are" not "data is"
- [ ] Page limit respected
