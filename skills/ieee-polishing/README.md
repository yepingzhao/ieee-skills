# ieee-polishing

Polish, restructure, or translate academic prose into IEEE-leaning technical English.

## What it does
- Restructures paragraphs for IEEE logical flow
- Tightens verbose prose to meet page limits
- Converts Chinese academic drafts to IEEE English
- Aligns with IEEE terminology and citation conventions
- Flags unsupported claims and missing citations

## Status
Draft — rules defined, not yet tested on real examples.

## Key rules
| Domain | Rule |
|--------|------|
| Voice | Active voice preferred; passive acceptable in methods |
| Citations | Numbered [1], [2] in order of appearance |
| Sentence length | Target 15-25 words, hard cap at 35 |
| Precision | Numbers over adjectives; specific quantities required |
| Structure | Claim → evidence → citation → interpretation |
