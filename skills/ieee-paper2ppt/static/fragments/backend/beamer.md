# IEEE Beamer Backend

## Template
```latex
\documentclass{beamer}
\usetheme{Madrid}
\usecolortheme{default}
\title{...}
\author{...}
\institute{...}
\date{...}
\begin{document}
\frame{\titlepage}
\begin{frame}{Problem}
...
\end{frame}
\end{document}
```

## IEEE Beamer tips
- Use Madrid or Berkeley theme (clean, professional)
- Frame titles should be assertions, not section labels
- Include conference name/date in footer
