# IEEE Figure Contract

## Before any code
1. State the core conclusion this figure supports
2. Map the evidence chain: what data, what comparison, what conclusion
3. Classify the figure archetype: comparison / trend / distribution / spatial / network / composite
4. Set the export contract: format (.pdf preferred for IEEE), resolution (300 dpi min), dimensions (column width 3.5in, full page width 7.16in)
