# IEEE Conference Proceedings Formatting Reference

Shared reference for ieee-polishing and ieee-writing.

## Template
`\documentclass[conference]{IEEEtran}`. Always check the conference website for specific templates.

## Key differences from Transactions
| Aspect | Conference | Transactions |
|---|---|---|
| Page limit | 4-8 pages (strict) | 8-14 pages (guideline) |
| Abstract | 100-150 words | 150-250 words |
| Related Work | Often compressed | Usually separate section |
| Experiments | May be limited | Expected comprehensive |
| Appendix | Usually not allowed | Sometimes allowed |
| Blind review | Often double-blind | Usually single-blind |

## Camera-ready requirements
1. All fonts embedded in PDF
2. No page numbers (unless specified)
3. PDF/A compliance may be required
4. File size limits (typically 5-10 MB)
5. IEEE copyright clearance code
6. Mandatory author bios/photos for some conferences
