# IEEE Paper Type Taxonomy

IEEE publishes several distinct paper types.

## 1. Transaction / Journal Paper (Full Paper)
- **Length**: 8-14 pages IEEEtran double-column
- **Structure**: Abstract → Introduction → Related Work → Methodology → Experiments → Discussion → Conclusion
- **Criteria**: Technical novelty, soundness, experimental rigor, clarity

## 2. Conference Paper
- **Length**: 4-8 pages IEEEtran double-column
- **Structure**: Abstract → Introduction → Method → Results → Conclusion (compressed)
- **Criteria**: Novelty, correctness, clarity, conference relevance
- **Key trait**: Focused contribution; can be preliminary

## 3. Letters / Short Paper
- **Length**: 3-5 pages IEEEtran double-column
- **Structure**: Brief intro → method → key result → conclusion
- **Criteria**: Timeliness, correctness, brevity
- **Key trait**: Rapid communication of significant new results

## 4. Review / Survey Paper
- **Length**: 12-25+ pages
- **Structure**: Abstract → Introduction → Taxonomy → Detailed Survey → Comparative Analysis → Future Directions → Conclusion
- **Criteria**: Comprehensiveness, organization, critical analysis

## 5. Magazine Article
- **Length**: 4-8 pages single-column magazine format
- **Audience**: Broader IEEE membership
- **Key trait**: Accessible to non-specialists; tutorial tone

## Paper type detection
Detect from: (1) author statement, (2) draft length/structure, (3) target venue, (4) writing style.
