# IEEE Conclusion Drafting

## Structure
1. Restate problem and approach (1 sentence)
2. Summarize key contributions (numbered)
3. State main quantitative finding (1 sentence)
4. Suggest specific future work (1-2 sentences)
5. Closing impact statement (1 sentence)

## Rules
- No new information
- No citations (conclusion stands alone)
- Distinct from abstract in wording, not content
