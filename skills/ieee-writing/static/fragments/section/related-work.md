# IEEE Related Work Drafting

## Structure options
1. **Thematic**: Group by approach type (learning-based, rule-based, hybrid)
2. **Chronological**: Group by time period (foundational → recent → concurrent)
3. **Problem-based**: Group by sub-problem addressed

## Rules
- Cite only papers you've read
- Summarize each group, then critique: "These methods [strength] but [limitation]"
- Position your work relative to each group
- Transaction papers: 30-60 references; Conference: 15-30
