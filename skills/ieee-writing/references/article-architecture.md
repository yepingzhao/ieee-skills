# IEEE Article Architecture

## Transaction paper blueprint
Abstract (1p) → Introduction (2-3p) → Related Work (1-2p) → Method (2-3p) → Experiments (2-3p) → Discussion (1p) → Conclusion (0.5p) → References

## Conference paper blueprint
Abstract → Introduction (1p) → Method (1-2p) → Results (1-2p) → Conclusion (0.5p)
