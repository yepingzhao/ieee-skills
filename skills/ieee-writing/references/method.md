# IEEE Methods Section Writing — Deep Reference

## Principles
- Reproducibility: another researcher should be able to reimplement
- Modular description: each component described independently
- Rationale: why this design, not just what it is

## Algorithm presentation
```
\begin{algorithm}
\caption{...}
\begin{algorithmic}
\STATE Input: $X$, parameters $\theta$
\STATE Step 1: ...
\STATE Output: $Y$
\end{algorithmic}
\end{algorithm}
```
