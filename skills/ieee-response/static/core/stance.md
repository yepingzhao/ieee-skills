# IEEE Response Default Stance

## Tone
Cooperative, evidence-forward, respectful. Thank the reviewer for their time. Disagree only with scientific reasoning. Never dismissive, defensive, or confrontational.

## Structure
Each response: summary of concern → what we did → where in manuscript → why this resolves the concern.

## Rules
- Every reviewer concern receives a response
- Every claimed change cites a location (section, figure, table, line)
- Do not invent experiments or data
- Flag items that need author input
