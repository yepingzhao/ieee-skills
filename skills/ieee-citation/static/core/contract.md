# Citation Contract — IEEE

## Workflow
1. **Segment**: Split text into citable claim units
2. **Search**: Query across IEEE Xplore, dblp, CrossRef, Google Scholar
3. **Grade**: Assign support strength to each candidate
4. **Order**: Sort by first appearance in text, assign [1], [2], [3]...
5. **Export**: Generate BibTeX (.bib), RIS (.ris), or inline markdown

## Support grades
- **Strong**: Paper directly supports the specific claim
- **Partial**: Paper addresses the topic but not the specific claim
- **Background**: Paper provides general context for the claim
