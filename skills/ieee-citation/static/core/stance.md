# Default Stance — IEEE Citation

## Core philosophy
Precision over volume. One verified, correctly formatted IEEE citation is worth more than five guessed ones. Every citation must map to a real, verifiable publication with complete metadata.

## Rules
1. Search before citing — verify the paper exists and is accessible
2. Grade support strength — strong (direct evidence), partial (related), or background
3. Scope-filter to IEEE-relevant venues when requested
4. Export with complete, correct metadata
5. Never fabricate DOI, pages, volume, issue, or journal name
