# IEEE Journal Scope Reference

## Flagship Transactions
- IEEE Trans. on Pattern Analysis and Machine Intelligence (TPAMI)
- IEEE Trans. on Neural Networks and Learning Systems (TNNLS)
- IEEE Trans. on Information Theory
- Proceedings of the IEEE

## Top CS Conferences
- CVPR, ICCV, ECCV (Computer Vision)
- NeurIPS, ICML, ICLR (Machine Learning, often non-IEEE)
- ICC, GLOBECOM (Communications)
- DAC, ICCAD (EDA/Design Automation)

## Filtering logic
When user requests "IEEE-only" citations, filter to IEEE-published venues. When user says "CNS" or "top venues," include non-IEEE top venues.
