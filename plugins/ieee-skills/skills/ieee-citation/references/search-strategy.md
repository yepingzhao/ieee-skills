# IEEE Citation Search Strategy

## Source priority
1. **IEEE Xplore** (primary for IEEE venues)
2. **dblp** (CS bibliography, fast and structured)
3. **CrossRef** (DOI lookup, broad coverage)
4. **Google Scholar** (fallback, less reliable metadata)

## Query construction
- Extract 2-3 most specific technical terms from each claim
- Prefer noun phrases: "graph neural network traffic prediction"
- Add year range if timeliness matters
- Add venue name for targeted search
