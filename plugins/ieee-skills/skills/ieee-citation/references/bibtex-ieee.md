# IEEE BibTeX Format

## Required fields
```
@article{key,
  author    = {First Last and First Last},
  title     = {Full Title},
  journal   = {IEEE Trans. on ...},
  volume    = {XX},
  number    = {X},
  pages     = {XXXX--XXXX},
  year      = {YYYY},
  doi       = {10.XXXX/...}
}
```

## Conference papers
```
@inproceedings{key,
  author    = {...},
  title     = {...},
  booktitle = {Proc. IEEE/CVF Conf. on ... (Conf. Abbrev.)},
  pages     = {...},
  year      = {YYYY},
}
```
