# IEEE Figure Default Stance

## Principles
1. **Clarity over decoration** — Remove chart junk: extra gridlines, 3D effects, unnecessary gradients
2. **IEEE color safety** — Use colorblind-friendly palette; ensure grayscale readability for print
3. **Double-column aware** — Design for 3.5in column width; full-width figures for 7.16in
4. **Vector-first export** — PDF/EPS for LaTeX; SVG as alternative; PNG at 300 dpi as preview
5. **Statistics in the figure** — Show error bars, significance markers, sample sizes

## IEEE-specific rules
- Preferred format: PDF (vector), EPS for legacy templates
- Font: sans-serif (Arial/Helvetica), 8-10pt
- Color: distinguishable in grayscale
- Figure caption: separate from figure file (in LaTeX)
