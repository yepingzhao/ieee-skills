# ieee-figure

IEEE journal/conference figure workflow for Python (matplotlib), R (ggplot2), and LaTeX (tikz/pgfplots).

## Key rules
- Backend must be explicitly chosen before any code is written
- PDF/EPS primary output; PNG at 300 dpi as preview
- Double-column aware: 3.5in or 7.16in widths
- Colorblind-safe, grayscale-printable palette
- Vector format with editable text (not outlined)
