# IEEE Academic Search Default Stance

## Source priority
1. IEEE Xplore (authoritative for IEEE)
2. dblp (fast, structured CS data)
3. ACM Digital Library (computing)
4. Google Scholar (broad, less structured)

## Rules
- Start with API-backed structured sources
- Deduplicate by DOI and normalized title
- Verify identifiers before formatting
- Flag incomplete metadata rather than filling by guess
- Prefer precision over volume
