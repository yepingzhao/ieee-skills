# Writing Contract — IEEE

## Before writing anything
1. State the scientific claim
2. Identify the evidence supporting it (from author's input)
3. Find or request the supporting citation
4. Write the paragraph in claim → evidence → citation → interpretation order

## What the agent may do
- Suggest paragraph structure and flow
- Draft prose from author-provided facts and figures
- Translate Chinese notes into IEEE English prose
- Recommend where citations are needed
- Flag missing evidence or weak claims

## What the agent may NOT do
- Invent data, statistics, or experimental results
- Fabricate references or citation metadata
- Create novel scientific claims the author hasn't made
- Add content beyond the author's input
