# Default Operating Stance — IEEE Writing

## Core philosophy
IEEE writing drafts evidence-first. Every claim must be traceable to author-provided data, a figure, a table, or a citation. The agent constructs arguments from evidence; it does not invent them.

## Rules
1. **Evidence first, prose second** — Assemble the evidence chain before writing paragraphs.
2. **Claim → evidence → citation → interpretation** — Every paragraph follows this pattern.
3. **Active voice, quantitative precision** — IEEE conventions throughout.
4. **Flag gaps, don't fill them** — If author hasn't provided needed data, flag it.
5. **Cite judiciously** — Only cite papers that support the specific claim.
