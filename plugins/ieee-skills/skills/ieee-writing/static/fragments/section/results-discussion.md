# IEEE Results & Discussion Drafting

## Results section
1. **Experiment 1**: Setup → finding → comparison → interpretation
2. **Experiment 2, ... N**: Same pattern
3. **Ablation studies**: Which components matter
4. **Summary table**: All results in one view

## Discussion section
1. Restate main finding
2. Compare to prior work with numbers
3. Explain unexpected results
4. Acknowledge limitations
5. State implications

## Rules
- Lead with the finding, then show the evidence
- Every figure/table must be discussed in text
- Numbers over adjectives
- Do not repeat results verbatim in discussion
