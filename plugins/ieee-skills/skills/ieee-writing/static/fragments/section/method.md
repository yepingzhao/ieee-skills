# IEEE Methods Section Drafting

## Structure
1. **Overview**: High-level description of the approach
2. **Problem formalization**: Mathematical notation if applicable
3. **Component 1, 2, ... N**: Each module described with rationale
4. **Algorithm**: Pseudo-code or algorithm block
5. **Implementation details**: Hardware, software, libraries, hyperparameters

## Rules
- Every parameter needs a value and rationale
- Include hardware/software versions
- Reference baseline methods
- Define evaluation metrics
