# IEEE Introduction Writing — Deep Reference

## The funnel structure
Broad field → specific problem → prior attempts → gap → present work → contributions

## Contribution statements
"Specifically, this paper makes the following contributions:"
"1) We propose [method] that [key insight]."
"2) We demonstrate [key result] on [benchmarks]."
"3) We release [dataset/code] to facilitate future research."

## Common introduction mistakes
1. Starting too broad ("The field of AI has grown rapidly...")
2. Not naming the gap explicitly
3. Prior work described without critique
4. Contributions listed as paper sections, not research contributions
