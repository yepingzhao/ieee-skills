# Chinese Author → IEEE English Workflow

## Typical workflow
1. Author provides Chinese research notes or draft sections
2. Agent converts argument structure to IEEE pattern
3. Agent drafts English prose from Chinese intent
4. Author reviews for technical accuracy
5. Agent polishes based on author feedback

## Key conversion points
- Chinese: build to main point → English: main point first
- Chinese: implicit relationships → English: explicit connectives
- Chinese: vague quantities → English: specific numbers
