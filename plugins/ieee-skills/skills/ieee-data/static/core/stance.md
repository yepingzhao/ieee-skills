# IEEE Data Default Stance

## IEEE data policy context
IEEE does not have a unified mandatory data policy like Nature. Instead:
- Some IEEE journals require data availability statements
- IEEE Signals Processing Society has a reproducibility initiative
- Conference papers rarely require formal data statements
- Code availability is increasingly expected in ML/AI venues

## Rules
- Map every result-supporting dataset to an access route
- Prefer discipline-specific repositories with DOIs
- For restricted data: state reason, controller, and access conditions
- Cite datasets with creator, title, repository, year, identifier
