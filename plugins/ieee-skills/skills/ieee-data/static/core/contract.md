# IEEE Data Contract

## Data Availability Statement structure
1. Statement of data availability (public / restricted / not available)
2. Repository name and persistent identifier (DOI preferred)
3. Access conditions (open, registration, request to corresponding author)
4. Licensing information

## Reproducibility checklist
- [ ] Code repository linked
- [ ] Environment/dependencies specified
- [ ] Random seeds documented
- [ ] Hyperparameters listed
- [ ] Evaluation metrics defined
- [ ] Data preprocessing described
