# English Editing Rules (IEEE)

## Sentence rules
- Target 15-25 words per sentence; hard cap at 35
- One idea per sentence
- Active voice: "We implemented X using Y" not "X was implemented using Y"

## IEEE-specific rules
- All citations numbered [1], [2] in order of appearance
- Numbers ≥ 10 as numerals, < 10 spelled out (except with units)
- Define acronyms at first use
- *et al.* italicized
- "data are" (plural)
- "real-time" hyphenated
