# IEEE Terminology Ledger

Standardized technical writing conventions for IEEE papers. Used by ieee-polishing, ieee-writing, ieee-reader, ieee-paper2ppt.

## Voice and tense
| Section | Voice | Tense |
|---|---|---|
| Abstract | Active | Present (problem), Past (results) |
| Introduction | Active | Present (facts), Present perfect (prior work gaps) |
| Methodology | Active/Passive | Present (system description) |
| Results | Active preferred | Past (what was observed) |
| Discussion | Active | Present (interpretation) |
| Conclusion | Active | Present (contributions), Past (findings) |

IEEE prefers active voice: "We measured the latency" not "The latency was measured." Passive acceptable in Methodology when actor is irrelevant.

## Citation style
- Format: Numbered [1], [2], [3]
- Order: By first appearance in text
- Ranges: [1]-[5] for consecutive
- Placement: Before punctuation "as shown in [1]."
- Author mention: "Smith et al. [1] proposed..."

## IEEE-specific conventions
| Convention | Rule |
|---|---|
| Acronyms | Define at first use: "Support Vector Machine (SVM)" |
| Units | SI with space: "10 ms", "5 GHz" |
| Numbers | Spell out < 10; numerals ≥ 10 |
| Figures | "Fig. 1" in text |
| et al. | Italicized: *et al.* |
| i.e. / e.g. | With commas: "i.e.," and "e.g.," |
| data | Plural: "data are" |
| State-of-the-art | Hyphenated adjective form |
| Real-time | Always hyphenated |

## Prohibited phrases
- "It is worth noting that..." — Redundant
- "To the best of our knowledge..." — Imprecise
- "Very," "extremely" — Avoid intensifiers; use numbers
- "Obviously," "clearly" — Let evidence speak
- "This paper aims to..." — Use "This paper presents..."
