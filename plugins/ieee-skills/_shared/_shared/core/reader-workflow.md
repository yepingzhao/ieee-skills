# IEEE Reader Workflow

Shared reader workflow used by ieee-polishing and ieee-writing. Defines the standard operating procedure for reading and analyzing a manuscript draft before applying any edits.

## Reader workflow

1. **Classify the paper type** — Use `paper-type-taxonomy.md`. Transaction, conference, letter, or magazine article.
2. **Identify the section** — Each section has a distinct rhetorical job.
3. **Map the evidence chain** — IEEE reviewers expect quantitative evidence (metrics, baselines, ablations, statistical tests).
4. **Check citation style** — Numbered references [1], [2], [3] in order of appearance.
5. **Diagnose before treating** — Identify structural problems before editing sentences.
6. **Apply section-specific logic** — See the section-specific fragments.
7. **Verify terminology consistency** — Cross-reference against `terminology-ledger.md`.

## Failure modes

- **Polishing a paragraph that should be deleted** — Check if the paragraph serves the argument first.
- **Fixing grammar while ignoring structure** — IEEE reviewers care about technical correctness more than prose elegance.
- **Overwriting technical voice** — IEEE writing is precise and technical, not literary.
- **Applying Nature-style hedging** — IEEE uses active voice and direct statements.
