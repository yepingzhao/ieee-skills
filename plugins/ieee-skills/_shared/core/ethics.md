# IEEE Publication Ethics

Shared ethical guidelines for ieee-polishing and ieee-writing. Derived from the IEEE Code of Ethics.

## Core principles
1. **Authorship** — All authors must have substantial intellectual contributions.
2. **Plagiarism** — IEEE checks all submissions. Self-plagiarism is also a violation.
3. **Data fabrication** — Never create, alter, or selectively report data. Most serious violation.
4. **Duplicate publication** — Simultaneous submission to multiple venues is prohibited.
5. **Citation manipulation** — Cite only papers genuinely supporting claims.
6. **Conflict of interest** — Disclose financial and personal relationships.

## Agent enforcement
- Do not invent data, statistics, or results — flag gaps, don't fill them.
- Do not fabricate references — every citation must be verifiable.
- Do not overstate claims — "We demonstrate" requires quantitative evidence.
- Flag ethical concerns when detected — plagiarism, fabrication, citation manipulation.

## Boundaries
The agent is a writing assistant. It should flag concerns when detected, refuse to participate in fabrication, not judge author intent, and suggest the author consult IEEE guidelines.
