# IEEE Conference Taxonomy

Shared reference for ieee-polishing, ieee-writing, and ieee-reviewer.

## Conference tiers
| Tier | Description | Examples |
|---|---|---|
| Flagship | Top society-wide, 15-25% acceptance | ICCV, INFOCOM, ISCA |
| Top-tier | Leading TC conferences | CVPR, ICC, DAC, ISSCC |
| Mid-tier | Solid TC conferences | ISCAS, VTC, GLOBECOM |
| Workshop | Co-located with conferences | CVPR workshops |

## Conference paper conventions
1. **Shorter and denser** — 4-8 pages vs 8-14 for transactions
2. **Front-loaded** — Key contribution clear by end of page 1
3. **Preliminary results acceptable** — Unlike transactions
4. **Template compliance is strict** — Format violations can desk-reject
5. **Camera-ready deadline** — Must incorporate feedback by hard deadline
6. **Presentation requirement** — At least one author must register and present

## Conference vs journal review
| Aspect | Conference | Transaction |
|---|---|---|
| Review cycle | Single round, 2-4 months | Multiple rounds, 6-18 months |
| Reviewer count | Typically 3 | Typically 3-5 |
| Rebuttal | Usually none | Often author response allowed |
| Revision | Camera-ready only | Major revision possible |
